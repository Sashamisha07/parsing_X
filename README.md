# Парсер и Анализатор аккаунта X (Twitter): @rutradebtc

Инструменты для сбора и аналитики данных со страницы [https://x.com/rutradebtc](https://x.com/rutradebtc).

---

## 📁 Структура проекта

* `search_accounts.py` — Поиск аккаунтов X (Twitter) по ключевым словам и темам (крипта, альфа, солана, ангелы, дилфлоу) с живой выгрузкой метрик и генерацией персонального аутрича.
* `x_scraper.py` — Скрипт парсинга профиля и твитов (работает в быстром режиме без логина через эмуляцию TLS-отпечатков браузера, а также поддерживает авторизованный режим через сессионные куки).
* `x_analyzer.py` — Модуль анализа собранных данных: вовлеченность (ER), средние охваты, динамика каштагов/токенов ($DELTA, $EMBER и др.), смарт-контракты и топ постов.
* `rutradebtc_tweets.csv` — Выгруженные твиты в табличном формате (CSV) для Excel, Google Sheets или Pandas.
* `rutradebtc_data.json` — Полный структурированный JSON со всеми метаданными профиля и постами.
* `analysis_report.md` — Готовый аналитический отчет.

---

## 🚀 Быстрый старт

### 1. Запуск парсера (без авторизации)
Скрипт собирает актуальные метаданные профиля и свежие публикации:
```bash
python x_scraper.py
```
*Файлы `rutradebtc_tweets.csv` и `rutradebtc_data.json` обновятся автоматически.*

### 2. Запуск аналитического отчета
Анализирует выгруженные данные и обновляет Markdown-отчет:
```bash
python x_analyzer.py
```

## 🔍 Глубокий парсинг (история на сотни/тысячи твитов)

Так как платформа X (Twitter) блокирует пагинацию и скроллинг истории без авторизации:
1. Для сбора глубокой истории требуются 2 сессионные куки любого аккаунта X (`auth_token` и `ct0`):
   * Откройте `x.com` в браузере.
   * Нажмите `F12` -> Вкладка **Application** (или *Хранилище*) -> **Cookies** -> `https://x.com`.
   * Скопируйте значения `auth_token` и `ct0`.
2. Эти куки можно передать в парсер для пагинации всей истории аккаунта.
